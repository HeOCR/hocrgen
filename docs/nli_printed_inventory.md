# NLI digitized printed Hebrew books by IIIF licence slug (F8c2)

Generated by `python -m hocrgen.tools.nli_printed_inventory` from evidence captured on 2026-11-06; do not edit by hand. The per-book rows (record id, licence slug, admissible canvas count) are in [`nli_printed_inventory.json`](./nli_printed_inventory.json); the full inventory JSON stays outside the repository. Rights come from each manifest's `license` slug through the unchanged F8c gate (`decide_nli_rights`). Nothing here is a seed, a source or a release item.

## Method

- Search API query `language,exact,heb` with `material_type=book` and `availability_type=online_and_api_access`, 50 records a page.
- Population: 38756 records (count_mode). Pages past about page 400 return page 1, so 20000 records are reachable in the API's default order.
- Random cluster sample: 36 of 40 requested pages from pages 1-400 (seed 20261106); failed pages: [13, 121, 159, 174]; 31 search retries; 2032 requests at one per 1.1 s or slower; run status `ok`.
- Every `book` record's manifest was fetched. Multi-volume records (volume sequences without inline canvases) had up to 12 volume sequences fetched; the gate sees each volume's own canvas count, as for F8d2's pinned volume.
- Estimates are ratio estimates with per-page cluster standard errors (95% intervals). The window estimate covers the reachable records only. The extrapolation to the whole result set assumes the unreachable records look like the window; the bounds assume nothing (the unreachable records could all be in, or all out of, a class). The result order comes in large homogeneous blocks (see the per-page table), so the extrapolation is weak.
